# Criar o cabeçalho de uma folha de despesas

<!-- Fonte: Manual App CRM 1.5.docx, secção 8.4. -->

1. Na lista, prima o botão Criar ou o botão redondo com o sinal de adição.

![Captura de «Criar o cabeçalho de uma folha de despesas» relacionada com: 1. Na lista, prima o botão Criar ou o botão redondo com o sinal de adição.](../../../../assets/manual-1.5/image29.png)

2. Escreva uma Descrição que permita reconhecer o motivo ou o período das despesas. É obrigatória.

3. Se aplicável, selecione um Projeto.

4. Indique se a despesa é Reembolsável. Este valor será utilizado como opção inicial nas linhas que adicionar posteriormente.

5. Reveja a Moeda de reembolso. É determinada pela empresa ativa e aparece bloqueada neste ecrã. A moeda específica de cada despesa será indicada posteriormente na respetiva linha ou ticket.

6. Prima Guardar e confirme a criação.

7. Aguarde até aparecer o detalhe com um Identificador. A folha é criada no estado Rascunho e ainda não contém linhas.

ORDEM CORRETA: Primeiro, guarde o cabeçalho. Em seguida, a partir do detalhe da folha já criada, adicione linhas ou tickets. Não abandone a criação antes de obter o identificador da folha.
