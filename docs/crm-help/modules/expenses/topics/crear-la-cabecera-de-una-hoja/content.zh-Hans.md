# 创建费用单表头

<!-- 来源：Manual App CRM 1.5.docx，第 8.4 节。 -->

1. 在列表中，单击“创建”按钮或带加号的圆形按钮。

![与“创建费用单表头”相关的截图：1. 在列表中，单击“创建”按钮或带加号的圆形按钮。](../../../../assets/manual-1.5/image29.png)

2. 输入便于识别费用原因或期间的“说明”。此项为必填项。

3. 如适用，请选择“项目”。

4. 指明费用是否“可报销”。此值将用作之后所添加费用行的初始选项。

5. 检查“报销币种”。该币种由当前公司决定，并在此页面中锁定。之后可在每笔费用对应的费用行或票据中指定其具体币种。

6. 单击“保存”并确认创建。

7. 等待带有“标识符”的详细信息出现。费用单创建后处于“草稿”状态，尚不包含任何费用行。

正确顺序：先保存表头。然后在已创建费用单的详细信息中添加费用行或票据。在获得费用单标识符之前，请勿退出创建过程。
