# Create an expense sheet header

<!-- Source: CRM App Manual 1.5.docx, section 8.4. -->

1. In the list, press the Create button or the round button with the plus sign.

![Screenshot of "Create an expense sheet header" related to: 1. In the list, press the Create button or the round button with the plus sign.](../../../../assets/manual-1.5/image29.png)

2. Enter a Description that clearly identifies the purpose or period of the expenses. It is required.

3. If applicable, select a Project.

4. Specify whether the expense is Reimbursable. This value will be used as the initial option for lines you add later.

5. Review Reimbursement currency. It is determined by the active company and appears locked on this screen. The specific currency of each expense will be entered later on its line or ticket.

6. Press Save and confirm creation.

7. Wait for the detail view to appear with an Identifier. The sheet is created in Draft status and does not yet contain any lines.

CORRECT ORDER: Save the header first. Then, from the detail view of the sheet that has been created, add lines or tickets. Do not leave the creation screen before obtaining the sheet identifier.
