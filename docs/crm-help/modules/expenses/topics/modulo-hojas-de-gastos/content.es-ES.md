# Módulo Hojas de gastos

<!-- Fuente: Manual App CRM 1.5.docx, sección 8. -->

Una hoja de gastos agrupa los importes que una persona presenta para su tratamiento y, cuando corresponde, para su reembolso. La hoja se crea primero con sus datos generales. Después se añaden líneas, se crean tickets o se vinculan tickets existentes.
