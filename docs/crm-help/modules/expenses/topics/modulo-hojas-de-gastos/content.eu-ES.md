# Gastu-orriak modulua

<!-- Iturria: Manual App CRM 1.5.docx, 8. atala. -->

Gastu-orri batek pertsona batek izapidetzeko eta, hala dagokionean, itzultzeko aurkezten dituen zenbatekoak biltzen ditu. Lehenik, orria datu orokorrekin sortzen da. Ondoren, lerroak gehitzen dira, tiketak sortzen dira edo lehendik dauden tiketak lotzen dira.
