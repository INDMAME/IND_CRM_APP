# Módulo Folhas de despesas

<!-- Fonte: Manual App CRM 1.5.docx, secção 8. -->

Uma folha de despesas agrupa os montantes que uma pessoa apresenta para tratamento e, quando aplicável, para reembolso. A folha é criada primeiro com os seus dados gerais. Depois, são adicionadas linhas, são criados tickets ou são associados tickets existentes.
