# Modulo Note spese

<!-- Fonte: Manual App CRM 1.5.docx, sezione 8. -->

Una nota spese raggruppa gli importi che una persona presenta per il trattamento e, quando previsto, per il rimborso. La nota spese viene creata prima con i suoi dati generali. Successivamente si aggiungono righe, si creano ticket o si collegano ticket esistenti.
