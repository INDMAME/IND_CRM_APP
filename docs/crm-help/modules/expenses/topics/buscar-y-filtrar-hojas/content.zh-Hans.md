# 搜索和筛选费用单

<!-- 来源：Manual App CRM 1.5.docx，第 8.3 节。 -->

1. 单击“筛选”。

2. 仅使用所需字段：日期范围；在您有权管理下属时使用“用户”；以及“费用单”“项目”“币种”和“状态”。

3. 单击“应用”。

4. 单击“清除”以移除全部条件。
