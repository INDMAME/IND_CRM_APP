# Search and filter expense sheets

<!-- Source: CRM App Manual 1.5.docx, section 8.3. -->

1. Press Filter.

2. Use only the fields you need: date range, User if you manage subordinates, Expense sheet, Project, Currency, and Status.

3. Press Apply.

4. Press Clear to remove all criteria.
