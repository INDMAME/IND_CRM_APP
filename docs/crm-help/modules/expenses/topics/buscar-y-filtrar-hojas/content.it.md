# Cercare e filtrare le note spese

<!-- Fonte: Manual App CRM 1.5.docx, sezione 8.3. -->

1. Premere Filtro.

2. Utilizzare solo i campi necessari: intervallo di date, Utente se si gestiscono subordinati, Nota spese, Progetto, Valuta e Stato.

3. Premere Applica.

4. Premere Cancella per rimuovere tutti i criteri.
