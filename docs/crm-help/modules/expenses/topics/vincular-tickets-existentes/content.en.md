# Link existing tickets

<!-- Source: CRM App Manual 1.5.docx, section 8.9. -->

1. On an editable sheet, open Quick actions and press Link ticket.

2. Use the filters if you need to find the ticket by code, status, category, or AI processing.

3. Select one or more available tickets. Review the selection and the displayed amount.

4. Press Link ticket(s) and confirm.

5. Read the result. The application indicates how many were requested, linked, skipped, or failed. If any fail, note the reason before closing.

ERRORS: The option to modify a ticket that causes problems when it is linked to the expense sheet has been enabled. Read the error message carefully, correct the ticket, and repeat the linking process. If the ticket meets all requirements, it will be linked.
