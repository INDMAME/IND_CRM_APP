# Lehendik dauden tiketak lotzea

<!-- Iturria: Manual App CRM 1.5.docx, 8.9 atala. -->

1. Editatu daitekeen orri batean, ireki Ekintza azkarrak eta sakatu Lotu tiketa.

2. Erabili iragazkiak tiketa kodearen, egoeraren, kategoriaren edo AA bidezko prozesamenduaren arabera aurkitu behar baduzu.

3. Markatu erabilgarri dauden tiketetako bat edo batzuk. Berrikusi hautapena eta erakutsitako zenbatekoa.

4. Sakatu Lotu tiketa(k) eta berretsi.

5. Irakurri emaitza. Aplikazioak zenbat eskatu, lotu, saltatu edo huts egin duten adierazten du. Batek huts egiten badu, idatzi arrazoia itxi aurretik.

ERROREAK: Gastu-orriari lotzean arazoak izan ditzakeen tiketa aldatzeko aukera gaitu dugu. Irakurri arretaz errore-mezua, zuzendu tiketa eta errepikatu lotzeko prozesua. Tiketak beharrezko baldintza guztiak betetzen baditu, lotuta geratuko da.
