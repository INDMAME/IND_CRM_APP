# 关联现有票据

<!-- 来源：Manual App CRM 1.5.docx，第 8.9 节。 -->

1. 在可编辑的费用单中，打开“快捷操作”并单击“关联票据”。

2. 如需按代码、状态、类别或 AI 处理情况查找票据，请使用筛选条件。

3. 选中一个或多个可用票据。检查所选内容和显示的金额。

4. 单击“关联票据”，然后确认。

5. 阅读结果。应用会说明请求关联、成功关联、跳过或失败的票据数量。如果有票据失败，请在关闭结果前记下原因。

错误：我们已允许您修改在关联到费用单时出现问题的票据。请仔细阅读错误消息，纠正票据后重复关联流程。如果票据满足全部必要条件，则会成功关联。
