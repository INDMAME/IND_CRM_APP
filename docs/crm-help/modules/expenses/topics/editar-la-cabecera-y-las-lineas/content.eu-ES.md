# Goiburua eta lerroak editatzea

<!-- Iturria: Manual App CRM 1.5.docx, 8.10 atala. -->

Orria editagarria den bitartean, sakatu Editatu Deskribapena, Proiektua edo Itzulgarria aldatzeko. Proiektua edo Itzulgarria aldatzen baduzu eta lerroak badaude, aplikazioak lerro guztiak eguneratu nahi dituzun galde diezazuke. Irakurri galdera eta berretsi balio berria oro har aplikatu nahi baduzu bakarrik.

Goiburuko Itzulketaren dibisa blokeatuta dago, enpresak zehazten duelako. Gastuaren dibisa eta Kanbio-tasa lerro edo tiket bakoitzean berrikusten dira. Erregistro bat jatorriagatik edo egoeragatik blokeatuta badago, ez ezabatu informaziorik aldaketa behartzeko: kontsultatu barne-prozedura.
