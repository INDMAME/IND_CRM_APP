# Edit the header and lines

<!-- Source: CRM App Manual 1.5.docx, section 8.10. -->

While the sheet remains editable, press Edit to change Description, Project, or Reimbursable. If you change Project or Reimbursable when lines already exist, the application may ask whether you want to update all lines. Read the question and confirm only if you want to apply the new value to every line.

The header's Reimbursement currency is locked because it is determined by the company. Expense currency and Exchange rate are reviewed on each line or ticket. If a record is locked because of its origin or status, do not delete information to force the change: follow the internal procedure.
