# 使用费用助手

<!-- 来源：Manual App CRM 1.5.docx，第 8.3.1 节。 -->

列表可能会在表单左下角显示用于打开“费用助手”的按钮。该助手仅分析当前查询中已加载的费用单。请先应用筛选条件并等待加载完成，然后再打开助手。

![与“使用费用助手”相关的截图：列表可能会在表单左下角显示用于打开“费用助手”的按钮。该助手仅分析当前查询中已加载的费用单。](../../../../assets/manual-1.5/image28.png)

您可以单击“摘要”“分析”或“异常”，也可以输入有关已加载费用单的问题，然后单击“发送”。

负责任地使用 AI：助手提供分析辅助，但可能出错。请在原始卡片中核对金额、用户、项目、币种和状态。助手的回答不会批准、拒绝或修改费用单，也不能代替人工检查。
