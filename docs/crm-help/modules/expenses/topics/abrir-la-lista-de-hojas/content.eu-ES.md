# Gastu-orrien zerrenda irekitzea

<!-- Iturria: Manual App CRM 1.5.docx, 8.2 atala. -->

1. Ireki alboko menua.

2. GASTUAK atalean, sakatu Gastu-orriak.

3. Itxaron txartelak agertu arte. Txartel bakoitzak identifikatzailea, deskribapena, jabea, data, dibisa, zenbatekoa, egoera, proiektua eta, halakorik badago, kontabilitate-egiaztagiria erakuts ditzake.
