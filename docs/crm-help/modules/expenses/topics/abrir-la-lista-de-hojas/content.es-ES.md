# Abrir la lista de hojas

<!-- Fuente: Manual App CRM 1.5.docx, sección 8.2. -->

1. Abra el menú lateral.

2. En GASTOS, pulse Hojas de gastos.

3. Espere a que aparezcan las tarjetas. Cada tarjeta puede mostrar el identificador, la descripción, el propietario, la fecha, la divisa, el importe, el estado, el proyecto y el justificante contable cuando exista.
