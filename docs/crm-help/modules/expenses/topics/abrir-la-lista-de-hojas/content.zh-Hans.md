# 打开费用单列表

<!-- 来源：Manual App CRM 1.5.docx，第 8.2 节。 -->

1. 打开侧边菜单。

2. 在“费用”下单击“费用单”。

3. 等待卡片出现。每张卡片可能显示标识符、说明、所有者、日期、币种、金额、状态、项目以及会计凭证（如有）。
