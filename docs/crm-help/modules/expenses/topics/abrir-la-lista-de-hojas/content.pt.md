# Abrir a lista de folhas de despesas

<!-- Fonte: Manual App CRM 1.5.docx, secção 8.2. -->

1. Abra o menu lateral.

2. Em DESPESAS, prima Folhas de despesas.

3. Aguarde até aparecerem os cartões. Cada cartão pode mostrar o identificador, a descrição, o proprietário, a data, a moeda, o montante, o estado, o projeto e o comprovativo contabilístico, quando exista.
