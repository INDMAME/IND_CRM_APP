# 从费用单创建票据

<!-- 来源：Manual App CRM 1.5.docx，第 8.8 节。 -->

1. 在可编辑的费用单中，打开“快捷操作”并单击“新建票据”。

2. 选择“使用相机”拍摄凭证，或选择“选择图片”使用设备中已保存的照片。

3. 请确保票据完整、光线充足、没有反光且文字清晰。确认图片并等待。应用会准备文件、创建票据，并尝试通过 AI 读取其数据。

4. 处理完成后，票据会以编辑模式打开。检查日期、币种、商户或说明、金额、类别以及识别出的明细行。AI 可帮助填写数据，但用户有责任核对这些数据。

5. 单击“保存”。只有正确完成此保存操作后，票据才会关联到费用单。在保存并确认数据正确之前，请勿关闭页面或返回。

请勿中途退出：从费用单中创建图片本身并不能完成该流程。票据会打开供您检查，且必须保存。如果未保存便退出，票据可能保持待处理状态，并且不会显示为已关联到费用单。支持最大 50 MB 的 JPG、JPEG、PNG 和 WEBP 文件。
