# Crear un ticket desde una hoja

<!-- Fuente: Manual App CRM 1.5.docx, sección 8.8. -->

1. En una hoja editable, abra Acciones rápidas y pulse Nuevo ticket.

2. Elija Usar cámara para fotografiar el justificante o Elegir imagen para utilizar una fotografía ya guardada en su dispositivo.

3. Procure que el ticket esté completo, bien iluminado, sin reflejos y con el texto legible. Confirme la imagen y espere. La aplicación prepara el archivo, crea el ticket e intenta leer sus datos mediante IA.

4. Al terminar se abre el ticket en modo edición. Revise la fecha, la divisa, el establecimiento o descripción, los importes, la categoría y las líneas reconocidas. La IA ayuda a rellenar datos, pero el usuario es responsable de comprobarlos.

5. Pulse Guardar. El ticket queda vinculado a la hoja solo al completar correctamente este guardado. No cierre ni vuelva atrás antes de guardarlo y asegurarse de que los datos estén correctos.

NO ABANDONAR: Crear la imagen no completa por sí solo el proceso desde una hoja. El ticket se abre para revisión y debe guardarse. Si sale sin guardar, puede quedar pendiente y no aparecer vinculado a la hoja. Se admiten JPG, JPEG, PNG y WEBP de hasta 50 MB.
