# Gastu-orriaren xehetasuna ulertzea

<!-- Iturria: Manual App CRM 1.5.docx, 8.5 atala. -->

Goiko aldean datu orokorrak daude: Deskribapena, Itzulketaren zenbatekoa, Itzulketaren dibisa, Egoera, Identifikatzailea, Itzulgarria, Proiektua, Jabea hala badagokio eta Egoeraren iruzkina halakorik badago. Beheko aldean gastu-lerroak agertzen dira.

Zirriborroa egoeran eta editatzeko baimenekin, ekintza azkarren botoiak Tiket berria, Lotu tiketa eta Lerro berria aukerak eskaintzen ditu. Orria irakurtzeko soilik denean, aukera horiek ez dira agertzen.
