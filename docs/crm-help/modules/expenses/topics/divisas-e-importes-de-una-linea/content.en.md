# Currencies and line amounts

<!-- Source: CRM App Manual 1.5.docx, section 8.7. -->

Expense currency is the currency in which the amount was paid. Reimbursement currency belongs to the sheet and depends on the company. Currency amount represents the original expense and Reimbursement amount represents the value that will be added to the sheet.

If both currencies are the same, Exchange rate remains at 100 and does not need to be entered. If they differ, the application attempts to obtain the rate for the relevant date. Review the result; if you change Exchange rate or Reimbursement amount, check both values again before saving.
