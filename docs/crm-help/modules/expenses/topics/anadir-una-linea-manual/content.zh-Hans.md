# 手动添加费用行

<!-- 来源：Manual App CRM 1.5.docx，第 8.6 节。 -->

1. 在可编辑的费用单中，打开“快捷操作”并单击“新建费用行”。

2. 填写费用“日期”。

3. 选择适当的“类别”（某些情况下，各公司对类别的定义不同）。

4. 输入清楚的“说明”。

5. 输入“单价”和“数量”。检查计算出的金额。

6. 选择“费用币种”，并检查“外币金额”“汇率”和“报销金额”。

7. 填写适用的“项目”“国际”“可报销”和其他字段。

8. 单击“保存”并确认。

必填字段：“说明”和“类别”必须填写。“单价”和“数量”必须大于零。对于“公里”类别，单价可以根据公司设置自动计算，并可能处于锁定状态。
