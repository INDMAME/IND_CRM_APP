# 基本术语表

<!-- 来源：Manual App CRM 1.5.docx，第 13 节。 -->

Web 应用：通过浏览器使用的程序，无需为每项功能安装专门的应用。

地址栏：浏览器顶部用于输入网页地址的区域。

草稿：费用单的初始状态，此时仍可补充和纠正内容。

按钮：单击后执行操作的页面元素。

字段：用于输入或选择数据的区域。

客户：与某次拜访相关的客户或实体。

币种：所使用的货币，例如 EUR、USD 或 GBP。

链接：打开另一个页面或界面的文本或按钮。

当前公司：应用当前正在使用其数据的公司。

状态：拜访、费用单或票据在其流程中的当前情况。

筛选器：用于减少显示结果的条件。

费用单：汇总费用行和费用凭证的记录。

AI：尝试从票据图片中提取数据的人工智能功能；其结果必须经过检查。

标识符：用于查找记录的唯一代码。

费用行：包含日期、类别、说明和金额的单项明细。

浏览器：用于打开网页的程序，例如 Microsoft Edge 或 Google Chrome。

权限：允许查看或执行某项功能的授权。

所有者：拜访或费用单所属的人员。

可报销：表示该金额是否属于根据公司规则应予报销的费用。

负责人：获授权审核并决定受管理用户费用单的人员。

票据：费用凭证的图片及其数据。

汇率：用于在不同币种之间换算金额的数值。

Voucher 或会计凭证：费用单处理过程中生成的会计参考编号。
