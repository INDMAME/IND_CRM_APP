# Glossário básico

<!-- Fonte: Manual App CRM 1.5.docx, secção 13. -->

Aplicação Web: programa utilizado a partir de um navegador sem instalar uma aplicação específica para cada função.

Barra de endereços: zona superior do navegador onde se escreve o endereço de uma página.

Rascunho: estado inicial de uma folha que ainda pode ser preenchida e corrigida.

Botão: elemento do ecrã que executa uma ação quando é premido.

Campo: espaço onde se escreve ou seleciona um dado.

Conta: cliente ou entidade com a qual uma visita está relacionada.

Moeda: moeda utilizada, por exemplo, EUR, USD ou GBP.

Ligação: texto ou botão que abre outro ecrã ou página.

Empresa ativa: empresa cujos dados estão a ser utilizados pela aplicação nesse momento.

Estado: situação atual de uma visita, folha ou ticket dentro do respetivo processo.

Filtro: critério que reduz os resultados apresentados.

Folha de despesas: registo que agrupa linhas e comprovativos de despesa.

IA: função de inteligência artificial que tenta extrair dados da imagem de um ticket; os seus resultados devem ser revistos.

Identificador: código único que permite localizar um registo.

Linha de despesa: detalhe individual com data, categoria, descrição e montante.

Navegador: programa para abrir páginas, como o Microsoft Edge ou o Google Chrome.

Permissão: autorização que permite ver ou executar uma função.

Proprietário: pessoa a quem pertence uma visita ou uma folha de despesas.

Reembolsável: indica se o montante corresponde a uma despesa que deve ser reembolsada de acordo com as regras da empresa.

Responsável: pessoa autorizada a rever e decidir sobre folhas de utilizadores geridos.

Ticket: imagem e dados de um comprovativo de despesa.

Taxa de câmbio: valor utilizado para converter montantes entre moedas.

Voucher ou comprovativo: referência contabilística gerada durante o tratamento da folha.
