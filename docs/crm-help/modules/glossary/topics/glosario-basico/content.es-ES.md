# Glosario básico

## Cómo utilizar el glosario

Consulte aquí el significado básico de los términos utilizados en el manual. Para conocer los pasos, las condiciones de edición o las acciones disponibles, acuda al procedimiento del módulo correspondiente.

## Términos de consulta

Aplicación web: programa que se utiliza desde un navegador sin instalar una aplicación específica para cada función.

Barra de direcciones: zona superior del navegador donde se escribe la dirección de una página.

Borrador: estado inicial de una hoja que todavía puede completarse y corregirse.

Botón: elemento de la pantalla que ejecuta una acción al pulsarlo.

Campo: espacio donde se escribe o selecciona un dato.

Cuenta: cliente o entidad con la que se relaciona una visita.

Divisa: moneda utilizada, por ejemplo EUR, USD o GBP.

Enlace: texto o botón que abre otra pantalla o página.

Empresa activa: empresa cuyos datos está utilizando la aplicación en ese momento.

Estado: situación actual de una visita, hoja o ticket dentro de su proceso.

Filtro: criterio que reduce los resultados mostrados.

Hoja de gastos: registro que agrupa líneas y justificantes de gasto.

IA: función de inteligencia artificial que intenta extraer datos de la imagen de un ticket; sus resultados deben revisarse.

Identificador: código único que permite localizar un registro.

Línea de gasto: detalle individual con fecha, categoría, descripción e importe.

Navegador: programa para abrir páginas, como Microsoft Edge o Google Chrome.

Permiso: autorización que permite ver o ejecutar una función.

Propietario: persona a la que pertenece una visita o una hoja de gastos.

Reembolsable: indica si el importe corresponde a un gasto que debe reembolsarse según las reglas de la empresa.

Responsable: persona autorizada para revisar y decidir sobre hojas de usuarios gestionados.

Ticket: imagen y datos de un justificante de gasto.

Tipo de cambio: valor utilizado para convertir importes entre divisas.

Voucher o justificante: referencia contable generada durante el tratamiento de la hoja.

## Términos de uso de la pantalla

Campo obligatorio: dato que debe completarse para que la aplicación acepte la operación en las condiciones indicadas por el formulario.

Confirmación: mensaje que solicita aceptar o cancelar una acción antes de ejecutarla.

Detalle: pantalla en la que se consulta un registro concreto y se muestran las acciones disponibles para él.

Modo edición: situación en la que se habilitan los campos que el usuario puede modificar.

Solo lectura: situación en la que se permite consultar los datos, pero no modificarlos desde esa pantalla.

## Relación entre tickets y hojas

Pendiente: estado de un ticket que todavía no está asignado a una hoja de gastos.

Asignado: estado de un ticket relacionado con una hoja de gastos.

Vincular ticket: asociar un justificante existente al destino seleccionado mediante la acción correspondiente de la hoja o línea.

Desvincular ticket: retirar una relación admitida desde la línea mediante esa acción; debe comprobarse el resultado antes de volver a utilizar el ticket.

Procesado por IA: indicador de procesamiento automático de la imagen; no acredita que una persona haya revisado sus datos.
