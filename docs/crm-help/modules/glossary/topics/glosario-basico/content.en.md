# Basic glossary

<!-- Source: CRM App Manual 1.5.docx, section 13. -->

Web application: a program used from a browser without installing a specific application for each function.

Address bar: the area at the top of the browser where a page address is entered.

Draft: the initial status of a sheet that can still be completed and corrected.

Button: a screen element that performs an action when pressed.

Field: a space where information is entered or selected.

Account: the customer or entity associated with a visit.

Currency: the currency used, for example EUR, USD, or GBP.

Link: text or a button that opens another screen or page.

Active company: the company whose data the application is currently using.

Status: the current situation of a visit, sheet, or ticket within its process.

Filter: a criterion that reduces the results displayed.

Expense sheet: a record that groups expense lines and supporting documents.

AI: an artificial intelligence function that attempts to extract information from a ticket image; its results must be reviewed.

Identifier: a unique code used to find a record.

Expense line: an individual entry with a date, category, description, and amount.

Browser: a program used to open pages, such as Microsoft Edge or Google Chrome.

Permission: authorization that allows a function to be viewed or performed.

Owner: the person to whom a visit or expense sheet belongs.

Reimbursable: indicates whether the amount is an expense that must be reimbursed according to company rules.

Manager: a person authorized to review and make decisions about the sheets of managed users.

Ticket: the image and data from an expense receipt.

Exchange rate: the value used to convert amounts between currencies.

Voucher or supporting document: an accounting reference generated while the sheet is being processed.
