# Open the CRM

<!-- Source: CRM App Manual 1.5.docx, section 4.1. -->

1. Open the browser.

2. Press the address bar, type https://crm.insertec.biz:7702/, and press Enter. If the company has provided you with a shortcut or a different address, always use that corporate access method.

3. Wait for the application or the Microsoft sign-in screen to appear.
