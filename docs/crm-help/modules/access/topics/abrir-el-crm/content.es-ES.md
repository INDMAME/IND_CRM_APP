# Abrir el CRM

<!-- Fuente: Manual App CRM 1.5.docx, sección 4.1. -->

1. Abra el navegador.

2. Pulse la barra de direcciones, escriba https://crm.insertec.biz:7702/ y pulse Enter. Si la empresa le ha proporcionado un acceso directo o una dirección distinta, utilice siempre ese acceso corporativo.

3. Espere hasta que aparezca la aplicación o la pantalla de identificación de Microsoft.
