# Iniciar sessão

<!-- Fonte: Manual App CRM 1.5.docx, secção 4.2. -->

1. No ecrã Bem-vindo, prima Entrar com a Microsoft.

![Captura de «Iniciar sessão» relacionada com: 1. No ecrã Bem-vindo, prima Entrar com a Microsoft.](../../../../assets/manual-1.5/image2.png)

2. Se aparecer uma lista de contas, selecione a sua conta empresarial.

3. Se solicitado, escreva a sua palavra-passe empresarial e prima Seguinte ou Iniciar sessão.

4. Se for solicitada uma verificação adicional, aprove o aviso na aplicação de autenticação ou introduza o código recebido. Este passo pode não aparecer em todos os acessos.

5. Aguarde até ser apresentada a página principal do CRM.

> **SEGURANÇA:** Nunca inclua numa captura deste manual uma palavra-passe, um código de verificação, um número de telefone pessoal nem informação confidencial.
