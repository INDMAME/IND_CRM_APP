# Accedere

<!-- Fonte: Manual App CRM 1.5.docx, sezione 4.2. -->

1. Nella schermata Benvenuto, premere Accedi con Microsoft.

![Schermata di «Accedere» relativa a: 1. Nella schermata Benvenuto, premere Accedi con Microsoft.](../../../../assets/manual-1.5/image2.png)

2. Se viene visualizzato un elenco di account, selezionare il proprio account aziendale.

3. Se richiesto, scrivere la password aziendale e premere Avanti o Accedi.

4. Se viene richiesta una verifica aggiuntiva, approvare la notifica nell'applicazione di autenticazione oppure inserire il codice ricevuto. Questo passaggio potrebbe non comparire a ogni accesso.

5. Attendere che venga visualizzata la pagina principale del CRM.

> **SICUREZZA:** Non includere mai in una schermata di questo manuale una password, un codice di verifica, un numero di telefono personale o informazioni riservate.
