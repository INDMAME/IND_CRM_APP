# 登录

<!-- 来源：Manual App CRM 1.5.docx，第 4.2 节。 -->

1. 在“欢迎”页面上，单击“使用 Microsoft 登录”。

![与“登录”相关的截图：1. 在“欢迎”页面上，单击“使用 Microsoft 登录”。](../../../../assets/manual-1.5/image2.png)

2. 如果出现帐户列表，请选择您的公司帐户。

3. 如果系统要求，请输入公司密码，然后单击“下一步”或“登录”。

4. 如果系统要求进行额外验证，请在身份验证应用中批准通知，或输入收到的验证码。并非每次登录都会出现此步骤。

5. 等待 CRM 主页显示。

> **安全提示：** 本手册的任何截图中都不得包含密码、验证码、个人电话号码或机密信息。
