# Helbidea gogokoetan gordetzea

<!-- Iturria: Manual App CRM 1.5.docx, 4.3 atala. -->

Urrats hau aukerakoa da. CRM irekita dagoenean, sakatu helbide-barraren amaieran dagoen izarra, idatzi CRM Insertec bezalako izen bat eta berretsi. Hurrengo sarbideetan Gogokoak ataletik ireki ahal izango duzu, helbidea berriro idatzi gabe.
