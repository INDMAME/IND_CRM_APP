# Guardar o endereço como favorito

<!-- Fonte: Manual App CRM 1.5.docx, secção 4.3. -->

Este passo é opcional. Quando o CRM estiver aberto, prima a estrela situada no final da barra de endereços, escreva um nome como CRM Insertec e confirme. Nos acessos seguintes, poderá abri-lo a partir dos Favoritos sem voltar a escrever o endereço.
