# Disconnettersi

<!-- Fonte: Manual App CRM 1.5.docx, sezione 4.4. -->

1. Aprire il menu laterale sinistro.

2. Premere il proprio nome utente nella parte inferiore.

3. Premere Disconnetti e attendere di tornare alla schermata di accesso.
