# Collegamenti ricevuti via e-mail

<!-- Fonte: Manual App CRM 1.5.docx, sezione 10.5. -->

Un'e-mail di approvazione può includere un collegamento diretto alla nota spese. Premere il collegamento, identificarsi se richiesto e attendere. L'applicazione può passare alla società corretta prima di aprire il dettaglio. Il collegamento non concede autorizzazioni aggiuntive: sarà possibile vedere o utilizzare la nota spese solo se il proprio utente è autorizzato.
