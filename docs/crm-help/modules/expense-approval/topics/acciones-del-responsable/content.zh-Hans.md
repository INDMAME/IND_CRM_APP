# 负责人的操作

<!-- 来源：Manual App CRM 1.5.docx，第 10.4 节。 -->

查看受管理人员（下属）的费用单时，负责人不能编辑其内容。在“已申请审批”状态下，可以“批准”或“拒绝”；在“已批准”状态下，可以“撤销批准”；在“已拒绝”状态下，可以“撤销拒绝”。这些撤销操作会将费用单恢复为系统预定的上一状态。

单击状态操作时，会出现带有“状态备注”字段的确认提示。请输入有用的说明，特别是在拒绝或撤销决定时；请仅在检查标识符和所有者后确认。

> **操作已禁用：** 如果费用单既没有费用行，也没有大于零的总金额，状态操作可能会保持禁用。请在申请或执行状态更改前添加或纠正费用。

> **会计锁定：** “已付款”或已有会计凭证的费用单会在 Web 应用中锁定。请勿通过删除相关数据来尝试修改；请咨询负责部门。
