# Abrir o histórico de visitas

<!-- Fonte: Manual App CRM 1.5.docx, secção 7.1. -->

1. Abra o menu lateral.

2. Prima VISITAS. O Histórico será aberto.

3. Aguarde até aparecerem os cartões de resultados. Cada cartão resume uma visita e pode incluir a data, a conta, a descrição, o tipo, o meio de contacto e o proprietário, consoante os dados disponíveis e as suas permissões.
