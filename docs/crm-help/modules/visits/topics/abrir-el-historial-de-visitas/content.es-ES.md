# Abrir el historial de visitas

<!-- Fuente: Manual App CRM 1.5.docx, sección 7.1. -->

1. Abra el menú lateral.

2. Pulse VISITAS. Se abrirá el Historial.

3. Espere a que aparezcan las tarjetas de resultados. Cada tarjeta resume una visita y puede incluir la fecha, la cuenta, la descripción, el tipo, el medio de contacto y el propietario, según los datos disponibles y sus permisos.
