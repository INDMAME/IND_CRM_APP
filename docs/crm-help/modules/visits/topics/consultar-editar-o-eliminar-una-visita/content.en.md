# View, edit, or delete a visit

<!-- Source: CRM App Manual 1.5.docx, section 7.6. -->

1. On the History screen, press the visit card.

2. Review the information on the Detail screen.

3. If Edit appears and you need to change the activity, press it, modify the permitted fields, and press Save. Confirm the action when the window appears.

4. If Delete appears and you are completely certain, press it and read the warning. Deletion should not be used to correct a minor uncertainty; cancel and ask for guidance first if you are unsure.

The account and contacts used during creation are not editable fields in the current detail view. If the visit was created for the wrong account, do not change other information to make it look like a different account; follow the internal correction procedure.
