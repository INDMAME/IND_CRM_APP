# Consultar, editar ou eliminar uma visita

<!-- Fonte: Manual App CRM 1.5.docx, secção 7.6. -->

1. No Histórico, prima o cartão da visita.

2. Reveja os dados no ecrã Detalhe.

3. Se aparecer Editar e precisar de alterar a atividade, prima-o, altere os campos permitidos e prima Guardar. Confirme a ação quando a janela aparecer.

4. Se aparecer Eliminar e tiver a certeza absoluta, prima-o e leia o aviso. A eliminação não deve ser utilizada para corrigir uma dúvida menor; cancele e peça esclarecimentos antes, caso não tenha a certeza.

A conta e os contactos utilizados durante a criação não são campos editáveis no detalhe atual. Se a visita tiver sido criada para uma conta errada, não altere outros dados para simular outra conta; siga o procedimento interno de correção.
