# Filtrar o histórico de visitas

<!-- Fonte: Manual App CRM 1.5.docx, secção 7.2. -->

![Captura da secção «Filtrar o histórico de visitas» do manual CRM.](../../../../assets/manual-1.5/image11.png)

1. Prima Filtro na barra superior.

2. Escolha um período rápido, por exemplo, 7 dias, 30 dias ou 90 dias. Também pode escolher Data para indicar um intervalo manual.

3. Se necessário, selecione uma Conta. Se tiver colaboradores visíveis, também pode escolher um Proprietário ou a opção Todos os meus subordinados.

4. Prima Aplicar para executar a pesquisa.

5. Prima Limpar para remover os filtros e começar de novo.

NAVEGAÇÃO: Ao abrir uma visita e voltar ao histórico, a aplicação tenta conservar os filtros, a página e a posição anteriores. Evite abrir novamente o menu desde o início se pretender regressar ao mesmo ponto.
