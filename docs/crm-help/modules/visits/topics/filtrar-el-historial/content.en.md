# Filter visit history

<!-- Source: CRM App Manual 1.5.docx, section 7.2. -->

![Screenshot of the "Filter visit history" section of the CRM manual.](../../../../assets/manual-1.5/image11.png)

1. Press Filter in the top bar.

2. Choose a quick period, such as 7 days, 30 days, or 90 days. You can also choose Date to specify a custom range.

3. If necessary, select an Account. If staff members are visible to you, you can also choose an Owner or the All my subordinates option.

4. Press Apply to run the search.

5. Press Clear to remove the filters and start again.

NAVIGATION: When you open a visit and return to the history, the application attempts to preserve the filters, page, and previous position. Avoid reopening the menu from the beginning if you want to return to the same point.
