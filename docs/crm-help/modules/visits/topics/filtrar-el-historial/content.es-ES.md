# Filtrar el historial

<!-- Fuente: Manual App CRM 1.5.docx, sección 7.2. -->

![Captura de la sección «Filtrar el historial» del manual CRM.](../../../../assets/manual-1.5/image11.png)

1. Pulse Filtro en la barra superior.

2. Elija un periodo rápido, por ejemplo 7 días, 30 días o 90 días. También puede escoger Fecha para indicar un intervalo manual.

3. Si lo necesita, seleccione una Cuenta. Si tiene personal visible, también puede elegir un Propietario o la opción Todos mis subordinados.

4. Pulse Aplicar para ejecutar la búsqueda.

5. Pulse Borrar para retirar los filtros y empezar de nuevo.

NAVEGACIÓN: Al abrir una visita y volver al historial, la aplicación intenta conservar los filtros, la página y la posición anterior. Evite abrir de nuevo el menú desde cero si desea regresar al mismo punto.
