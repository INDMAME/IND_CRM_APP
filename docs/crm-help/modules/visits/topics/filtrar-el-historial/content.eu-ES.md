# Historia iragaztea

<!-- Iturria: Manual App CRM 1.5.docx, 7.2 atala. -->

![CRM eskuliburuko «Historia iragaztea» atalaren pantaila-argazkia.](../../../../assets/manual-1.5/image11.png)

1. Sakatu Iragazkia goiko barran.

2. Hautatu aldi azkar bat, adibidez 7 egun, 30 egun edo 90 egun. Data ere hauta dezakezu eskuzko tarte bat adierazteko.

3. Behar baduzu, hautatu Kontua. Langileak ikusgai badituzu, Jabea edo Nire mendeko guztiak aukera ere hauta dezakezu.

4. Sakatu Aplikatu bilaketa egiteko.

5. Sakatu Garbitu iragazkiak kentzeko eta berriro hasteko.

NABIGAZIOA: Bisita bat ireki eta historiara itzultzean, aplikazioa iragazkiak, orria eta aurreko kokapena mantentzen saiatzen da. Puntu berera itzuli nahi baduzu, ez ireki berriro menua hasieratik.
