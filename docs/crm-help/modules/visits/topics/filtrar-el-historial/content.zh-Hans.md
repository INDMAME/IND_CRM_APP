# 筛选拜访记录

<!-- 来源：Manual App CRM 1.5.docx，第 7.2 节。 -->

![CRM 手册“筛选拜访记录”一节的截图。](../../../../assets/manual-1.5/image11.png)

1. 单击顶部栏中的“筛选”。

2. 选择快捷时间段，例如 7 天、30 天或 90 天。您也可以选择“日期”来指定自定义时间范围。

3. 如有需要，请选择一个“客户”。如果您可以查看其他人员，还可以选择“负责人”或“我的所有下属”。

4. 单击“应用”以执行搜索。

5. 单击“清除”以移除筛选条件并重新开始。

导航：打开一次拜访并返回记录页面时，应用会尽量保留之前的筛选条件、页码和位置。如果希望回到原来的位置，请避免从菜单重新进入该页面。
