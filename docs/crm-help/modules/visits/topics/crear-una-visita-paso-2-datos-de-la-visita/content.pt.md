# Criar uma visita: passo 2, dados da visita

<!-- Fonte: Manual App CRM 1.5.docx, secção 7.4. -->

1. Reveja a Data. Por predefinição, é proposta a data atual.

2. Selecione o Tipo de visita.

3. Selecione o Meio de contacto, quando aplicável.

4. Escreva uma Descrição breve, com um máximo de 200 caracteres.

5. Abra Comentários e escreva a explicação principal da visita. Comentários é obrigatório. Antecedentes e Conclusões podem ser preenchidos quando acrescentarem informação útil.

6. Reveja os campos obrigatórios: Conta, Tipo de visita, Descrição e Comentários. Os contactos, o meio de contacto, os antecedentes e as conclusões não impedem a criação se ficarem vazios.

7. Prima Criar ou Guardar na barra superior.

8. Em Confirmar criação, reveja a pergunta e prima Aceitar para criar a visita ou Cancelar para voltar ao formulário.
