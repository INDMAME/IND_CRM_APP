# Create a visit: step 2, visit details

<!-- Source: CRM App Manual 1.5.docx, section 7.4. -->

1. Check the Date. The current date is suggested by default.

2. Select the Visit type.

3. Select the Contact method when applicable.

4. Enter a brief Description, up to 200 characters.

5. Open Comments and enter the main explanation of the visit. Comments is required. Background and Conclusions can be completed when they provide useful information.

6. Review the required fields: Account, Visit type, Description, and Comments. Contacts, contact method, background, and conclusions do not prevent creation if left empty.

7. Press Create or Save in the top bar.

8. In Confirm creation, review the question and press Accept to create the visit or Cancel to return to the form.
