# Bisita sortzea: 2. urratsa, bisitaren datuak

<!-- Iturria: Manual App CRM 1.5.docx, 7.4 atala. -->

1. Berrikusi Data. Lehenespenez uneko data proposatzen da.

2. Hautatu Bisita mota.

3. Hautatu Harremanetarako bidea, hala badagokio.

4. Idatzi Deskribapen labur bat, gehienez 200 karakterekoa.

5. Ireki Iruzkinak eta idatzi bisitaren azalpen nagusia. Iruzkinak nahitaezkoa da. Aurrekariak eta Ondorioak bete daitezke informazio erabilgarria ematen dutenean.

6. Berrikusi nahitaezko eremuak: Kontua, Bisita mota, Deskribapena eta Iruzkinak. Kontaktuek, harremanetarako bideak, aurrekariek eta ondorioek ez dute sorkuntza eragozten hutsik geratzen badira.

7. Sakatu Sortu edo Gorde goiko barran.

8. Berretsi sorkuntza leihoan, berrikusi galdera eta sakatu Onartu bisita sortzeko edo Utzi inprimakira itzultzeko.
