# Criar uma visita: passo 1, conta e contactos

<!-- Fonte: Manual App CRM 1.5.docx, secção 7.3. -->

1. No Histórico, prima o botão Criar ou o botão redondo com o sinal de adição.

2. Em Conta, escreva pelo menos quatro caracteres do nome ou código que pretende pesquisar. Em seguida, prima a lupa, a tecla Enter ou a seta do campo.

3. Aguarde até aparecerem resultados e prima a conta correta.

4. Se pretender associar contactos, abra o campo de contactos e selecione um ou vários. Os contactos são opcionais: pode criar uma visita sem selecionar nenhum.

5. Prima Avançar.
