# Testu-editorea eta diktaketa

<!-- Iturria: Manual App CRM 1.5.docx, 7.5 atala. -->

Iruzkinak, Aurrekariak edo Ondorioak sakatzean, pantaila osoko editore bat irekitzen da. Idatzi testua eta sakatu Gorde inprimakira itzultzeko. Mikrofonoa editatzeko moduan erabilgarri dagoenean, diktatu dezakezu. Transkripzio berri batek editoreko eduki osoa ordezten du; berrikusi beti emaitza gorde aurretik, hitz okerrak izan baititzake.
