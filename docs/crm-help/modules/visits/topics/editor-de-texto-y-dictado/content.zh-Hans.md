# 文本编辑器和语音听写

<!-- 来源：Manual App CRM 1.5.docx，第 7.5 节。 -->

单击“备注”“背景”或“结论”时，会打开全屏编辑器。输入文本后，单击“保存”将内容返回表单。编辑模式中有麦克风可用时，您可以进行语音听写。新的转写结果会替换编辑器中的全部内容；由于其中可能包含错误词语，请务必在保存前检查结果。
