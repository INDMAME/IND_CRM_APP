# Text editor and dictation

<!-- Source: CRM App Manual 1.5.docx, section 7.5. -->

Pressing Comments, Background, or Conclusions opens a full-screen editor. Enter the text and press Save to return it to the form. When the microphone is available in edit mode, you can dictate. A new transcription replaces all of the editor's content; always review the result before saving because it may contain incorrect words.
