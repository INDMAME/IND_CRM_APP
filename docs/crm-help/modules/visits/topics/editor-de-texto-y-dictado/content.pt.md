# Editor de texto e ditado

<!-- Fonte: Manual App CRM 1.5.docx, secção 7.5. -->

Ao premir Comentários, Antecedentes ou Conclusões, abre-se um editor em ecrã inteiro. Escreva o texto e prima Guardar para o devolver ao formulário. Quando o microfone estiver disponível no modo de edição, pode ditar. Uma nova transcrição substitui todo o conteúdo do editor; reveja sempre o resultado antes de guardar, porque pode conter palavras incorretas.
