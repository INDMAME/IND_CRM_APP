# Editor di testo e dettatura

<!-- Fonte: Manual App CRM 1.5.docx, sezione 7.5. -->

Premendo Commenti, Informazioni precedenti o Conclusioni si apre un editor a schermo intero. Scrivere il testo e premere Salva per riportarlo nel modulo. Quando il microfono è disponibile in modalità modifica, è possibile dettare. Una nuova trascrizione sostituisce l'intero contenuto dell'editor; verificare sempre il risultato prima di salvare, perché potrebbe contenere parole errate.
