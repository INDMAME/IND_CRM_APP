# Create a ticket from the Tickets module

<!-- Source: CRM App Manual 1.5.docx, section 9.2. -->

1. Press the Create button or the round button with the plus sign.

2. Choose Use camera or Choose image.

3. Wait for processing to finish.

4. Review all ticket data and lines in edit mode.

5. Press Save.

> **REVIEW REQUIRED:** Automatic reading may confuse dates, decimal separators, currencies, quantities, or categories. Compare the fields with the original image before saving.
