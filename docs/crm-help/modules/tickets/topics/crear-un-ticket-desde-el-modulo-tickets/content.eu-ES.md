# Tiketak modulutik tiketa sortzea

<!-- Iturria: Manual App CRM 1.5.docx, 9.2 atala. -->

1. Sakatu Sortu botoia edo plus ikurra duen botoi biribila.

2. Hautatu Erabili kamera edo Hautatu irudia.

3. Itxaron prozesamendua amaitu arte.

4. Berrikusi tiketaren datu eta lerro guztiak editatzeko moduan.

5. Sakatu Gorde.

> **NAHITAEZKO BERRIKUSPENA:** Irakurketa automatikoak datak, bereizle hamartarrak, dibisak, kopuruak edo kategoriak nahas ditzake. Konparatu eremuak jatorrizko irudiarekin gorde aurretik.
