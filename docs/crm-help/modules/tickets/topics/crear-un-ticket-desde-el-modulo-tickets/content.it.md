# Creare un ticket dal modulo Ticket

<!-- Fonte: Manual App CRM 1.5.docx, sezione 9.2. -->

1. Premere il pulsante Crea o il pulsante rotondo con il segno più.

2. Scegliere Usa fotocamera o Scegli immagine.

3. Attendere che l'elaborazione termini.

4. Verificare tutti i dati e le righe del ticket in modalità modifica.

5. Premere Salva.

> **VERIFICA OBBLIGATORIA:** La lettura automatica può confondere date, separatori decimali, valute, quantità o categorie. Confrontare i campi con l'immagine originale prima di salvare.
