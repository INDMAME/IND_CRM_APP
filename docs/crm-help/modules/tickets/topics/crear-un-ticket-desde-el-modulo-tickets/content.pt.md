# Criar um ticket a partir do módulo Tickets

<!-- Fonte: Manual App CRM 1.5.docx, secção 9.2. -->

1. Prima o botão Criar ou o botão redondo com o sinal de adição.

2. Escolha Utilizar câmara ou Escolher imagem.

3. Aguarde até que o processamento termine.

4. Reveja todos os dados e linhas do ticket no modo de edição.

5. Prima Guardar.

> **REVISÃO OBRIGATÓRIA:** A leitura automática pode confundir datas, separadores decimais, moedas, quantidades ou categorias. Compare os campos com a imagem original antes de guardar.
