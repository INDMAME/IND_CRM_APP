# Ticket status

<!-- Source: CRM App Manual 1.5.docx, section 9.3. -->

A Pending ticket has not yet been assigned to a sheet. An Assigned ticket is already linked to an expense sheet. If you need to change that relationship, the only current way to unlink a ticket is to delete it, upload it to the system again, and then link it to the appropriate expense sheet.
