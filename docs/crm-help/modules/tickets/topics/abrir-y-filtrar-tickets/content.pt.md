# Abrir e filtrar tickets

<!-- Fonte: Manual App CRM 1.5.docx, secção 9.1. -->

1. Abra o menu lateral.

2. Em DESPESAS, prima Tickets.

3. Utilize Filtro para pesquisar por Ticket, Estado, Categoria ou Processado por IA. Prima Aplicar para pesquisar ou Limpar para apagar os critérios.

4. Prima um cartão para abrir o respetivo detalhe.
