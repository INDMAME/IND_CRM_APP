# Aprire e filtrare i ticket

<!-- Fonte: Manual App CRM 1.5.docx, sezione 9.1. -->

1. Aprire il menu laterale.

2. In SPESE, premere Ticket.

3. Utilizzare Filtro per cercare per Ticket, Stato, Categoria o Elaborato tramite IA. Premere Applica per cercare o Cancella per pulire.

4. Premere una scheda per aprirne il dettaglio.
