# Tiketak ireki eta iragaztea

<!-- Iturria: Manual App CRM 1.5.docx, 9.1 atala. -->

1. Ireki alboko menua.

2. GASTUAK atalean, sakatu Tiketak.

3. Erabili Iragazkia Tiketa, Egoera, Kategoria edo AAk prozesatua irizpideen arabera bilatzeko. Sakatu Aplikatu bilatzeko edo Garbitu husteko.

4. Sakatu txartel bat haren xehetasuna irekitzeko.
