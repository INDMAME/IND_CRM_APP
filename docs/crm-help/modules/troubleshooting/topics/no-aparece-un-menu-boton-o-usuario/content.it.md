# Non appare un menu, un pulsante o un utente

<!-- Fonte: Manual App CRM 1.5.docx, sezione 12.3. -->

Verificare la società attiva e aggiornare la schermata. Se l'opzione continua a non comparire, la causa può essere legata alle autorizzazioni o alla gerarchia di gestione. Non utilizzare la sessione di un'altra persona.
