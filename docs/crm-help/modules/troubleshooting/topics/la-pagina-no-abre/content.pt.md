# A página não abre

<!-- Fonte: Manual App CRM 1.5.docx, secção 12.1. -->

1. Verifique se o dispositivo tem ligação.

2. Confirme se o endereço (https://crm.insertec.biz:7702/) está completo e não contém espaços.

3. Prima Atualizar uma única vez e aguarde.

4. Se o problema persistir, feche o navegador, volte a abri-lo e tente novamente.

5. Se outras páginas funcionarem, mas o CRM não, comunique a hora, o endereço e a mensagem apresentada.
