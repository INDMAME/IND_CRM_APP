# La página no abre

<!-- Fuente: Manual App CRM 1.5.docx, sección 12.1. -->

1. Compruebe que el dispositivo tiene conexión.

2. Revise que la dirección (https://crm.insertec.biz:7702/) esté completa y no contenga espacios.

3. Pulse Actualizar una sola vez y espere.

4. Si el problema continúa, cierre el navegador, vuelva a abrirlo y pruebe de nuevo.

5. Si otras páginas funcionan pero el CRM no, comunique la hora, la dirección y el mensaje mostrado.
