# The page does not open

<!-- Source: CRM App Manual 1.5.docx, section 12.1. -->

1. Check that the device has a connection.

2. Check that the address (https://crm.insertec.biz:7702/) is complete and does not contain spaces.

3. Press Refresh once and wait.

4. If the problem continues, close the browser, open it again, and retry.

5. If other pages work but the CRM does not, report the time, address, and displayed message.
