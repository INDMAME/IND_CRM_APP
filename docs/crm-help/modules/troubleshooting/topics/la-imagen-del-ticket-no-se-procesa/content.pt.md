# A imagem do ticket não é processada

<!-- Fonte: Manual App CRM 1.5.docx, secção 12.5. -->

1. Verifique se a imagem corresponde a um formato suportado e se não ultrapassa o limite indicado pela aplicação.

2. Se utilizar a câmara, conceda permissão apenas quando o navegador a solicitar para o CRM.

3. Tire uma nova fotografia com luz uniforme, sem cortar dados e evitando reflexos.

4. Se aparecer Repetir carregamento, utilize essa opção uma única vez e aguarde.

5. Se tiver sido criado um ticket parcial, anote o respetivo identificador antes de fechar a mensagem.
