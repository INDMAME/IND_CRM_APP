# The ticket image is not processed

<!-- Source: CRM App Manual 1.5.docx, section 12.5. -->

1. Check that the image is in a supported format and does not exceed the limit shown by the application.

2. If you use the camera, grant permission only when the browser requests it for the CRM.

3. Take a new photo with even lighting, without cropping information, and avoid glare.

4. If Retry upload appears, use it once and wait.

5. If a partial ticket was created, note its identifier before closing the message.
