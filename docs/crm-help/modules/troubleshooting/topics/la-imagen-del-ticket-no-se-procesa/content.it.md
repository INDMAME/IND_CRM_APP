# L'immagine del ticket non viene elaborata

<!-- Fonte: Manual App CRM 1.5.docx, sezione 12.5. -->

1. Verificare che l'immagine sia in un formato supportato e non superi il limite indicato dall'applicazione.

2. Se si utilizza la fotocamera, concedere l'autorizzazione solo quando il browser la richiede per il CRM.

3. Scattare una nuova fotografia con luce uniforme, senza tagliare i dati ed evitando i riflessi.

4. Se compare Riprova caricamento, utilizzarlo una sola volta e attendere.

5. Se è stato creato un ticket parziale, annotarne l'identificatore prima di chiudere il messaggio.
