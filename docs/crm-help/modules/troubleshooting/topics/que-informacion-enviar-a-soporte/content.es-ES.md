# Qué información enviar a soporte

<!-- Fuente: Manual App CRM 1.5.docx, sección 12.6. -->

## Objetivo

Facilitar a soporte la localización del registro y del problema.

## Antes de empezar

Conserve el mensaje antes de cerrar. Utilice el canal habitual del grupo en Microsoft Teams asignado a su compañía.

## Pasos

1. Reúna los datos de la tabla y una captura si aclara el error.
2. Explique qué esperaba y qué ocurrió después de pulsar la acción.
3. Revise la comunicación y envíela al canal interno correspondiente.

## Resultado y comprobación

Incluya el identificador para localizar el registro. Si el ticket quedó creado parcialmente, indíquelo expresamente.

## Datos que debe incluir

| Dato | Qué aportar |
| --- | --- |
| Usuario | Usuario corporativo, sin contraseña. |
| Empresa | Empresa activa durante la incidencia. |
| Pantalla y acción | Módulo, pantalla y botón u operación. |
| Registro | Identificador de visita, hoja o ticket, si existe. |
| Momento | Fecha y hora aproximadas. |
| Error | Mensaje completo. |
| Resultado esperado y observado | Qué esperaba y qué ocurrió. |
| Captura | Imagen sin contraseñas, códigos de acceso ni datos innecesarios. |

## Ejemplo

«En [empresa], Tickets, intenté guardar [identificador] a las [hora]. Esperaba corregir la descripción; tras confirmar apareció [mensaje]. Adjunto captura».
