# Laguntza-zerbitzura bidali beharreko informazioa

<!-- Iturria: Manual App CRM 1.5.docx, 12.6 atala. -->

- Zure erabiltzaile-izen korporatiboa, pasahitzik gabe.

- Enpresa aktiboa.

- Erabiltzen ari zinen modulua eta egiten ari zinen ekintza.

- Bisitaren, orriaren edo tiketaren identifikatzailea, halakorik badago.

- Gutxi gorabeherako data eta ordua.

- Errore-mezuaren testu osoa.

- Pasahitzik, sarbide-koderik edo beharrezkoa ez den daturik erakusten ez duen pantaila-argazkia.
