# L'accesso si ripete

<!-- Fonte: Manual App CRM 1.5.docx, sezione 12.2. -->

Chiudere tutte le schede del CRM, verificare di utilizzare l'account aziendale corretto e accedere di nuovo dall'accesso ufficiale. Non provare ripetutamente le password. Se l'account è bloccato o la verifica non riesce, contattare l'assistenza.
