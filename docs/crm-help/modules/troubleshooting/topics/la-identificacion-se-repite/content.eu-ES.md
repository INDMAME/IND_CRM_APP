# Identifikazioa errepikatzen da

<!-- Iturria: Manual App CRM 1.5.docx, 12.2 atala. -->

Itxi CRMaren fitxa guztiak, egiaztatu kontu korporatibo zuzena erabiltzen ari zarela eta sartu berriro sarbide ofizialetik. Ez probatu pasahitzak behin eta berriz. Kontua blokeatuta badago edo egiaztapenak huts egiten badu, jarri harremanetan laguntza-zerbitzuarekin.
