# A identificação repete-se

<!-- Fonte: Manual App CRM 1.5.docx, secção 12.2. -->

Feche todos os separadores do CRM, verifique se está a utilizar a conta empresarial correta e volte a entrar através do acesso oficial. Não experimente repetidamente palavras-passe. Se a conta estiver bloqueada ou a verificação falhar, contacte o suporte.
