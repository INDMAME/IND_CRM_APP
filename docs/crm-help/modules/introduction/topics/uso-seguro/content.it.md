# Uso sicuro

<!-- Fonte: Manual App CRM 1.5.docx, sezione 3.3. -->

- Non condividere la password né i codici di verifica.

- Verificare che l'indirizzo inizi con https:// e corrisponda all'accesso fornito dall'azienda.

- Se si utilizza un dispositivo condiviso, disconnettersi al termine e non consentire al browser di ricordare la password.

- Non inviare fotografie di ticket né dati dei clienti tramite canali non autorizzati.
