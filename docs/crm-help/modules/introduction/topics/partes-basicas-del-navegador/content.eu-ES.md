# Nabigatzailearen oinarrizko atalak

<!-- Iturria: Manual App CRM 1.5.docx, 3.2 atala. -->

Helbide-barra nabigatzailearen goiko aldean egon ohi da. Orrialde baten helbidea idazteko eremu luzea da. Ez da nahastu behar orrialde baten barruan dagoen bilatzailearekin.

1. Ireki Microsoft Edge edo Google Chrome.

2. Sakatu behin helbide-barraren barruan.

3. Idatzi edo itsatsi helbide osoa (https://crm.insertec.biz:7702/) eta sakatu Enter tekla.
