# Elementos básicos do navegador

<!-- Fonte: Manual App CRM 1.5.docx, secção 3.2. -->

A barra de endereços encontra-se normalmente na parte superior do navegador. É o espaço comprido onde se escreve o endereço de uma página. Não deve ser confundida com uma caixa de pesquisa dentro de uma página.

1. Abra o Microsoft Edge ou o Google Chrome.

2. Prima uma vez dentro da barra de endereços.

3. Escreva ou cole o endereço completo (https://crm.insertec.biz:7702/) e prima a tecla Enter.
