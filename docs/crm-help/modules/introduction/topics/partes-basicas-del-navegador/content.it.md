# Elementi di base del browser

<!-- Fonte: Manual App CRM 1.5.docx, sezione 3.2. -->

La barra degli indirizzi si trova normalmente nella parte superiore del browser. È lo spazio lungo in cui si scrive l'indirizzo di una pagina. Non deve essere confusa con un motore di ricerca presente all'interno di una pagina.

1. Aprire Microsoft Edge o Google Chrome.

2. Premere una volta all'interno della barra degli indirizzi.

3. Scrivere o incollare l'indirizzo completo (https://crm.insertec.biz:7702/) e premere il tasto Invio.
