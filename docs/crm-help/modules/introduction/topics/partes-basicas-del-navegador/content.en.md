# Basic browser elements

<!-- Source: CRM App Manual 1.5.docx, section 3.2. -->

The address bar is normally located at the top of the browser. It is the long space where you type a page address. It should not be confused with a search box inside a page.

1. Open Microsoft Edge or Google Chrome.

2. Click once inside the address bar.

3. Type or paste the full address (https://crm.insertec.biz:7702/) and press Enter.
