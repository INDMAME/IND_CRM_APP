# Cosa serve

<!-- Fonte: Manual App CRM 1.5.docx, sezione 3.1. -->

- Un computer, telefono o tablet autorizzato dall'azienda tramite l'indirizzo e-mail aziendale.

- Una connessione a Internet o alla rete aziendale prevista.

- Un account aziendale autorizzato ad accedere al CRM.

- Microsoft Edge o Google Chrome aggiornato. Un browser è il programma che consente di aprire pagine Internet.
