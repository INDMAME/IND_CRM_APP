# Qué necesita

<!-- Fuente: Manual App CRM 1.5.docx, sección 3.1. -->

- Un ordenador, teléfono o tableta autorizado por la empresa mediante su correo empresarial.

- Conexión a Internet o a la red corporativa que corresponda.

- Una cuenta corporativa con permiso para entrar en el CRM.

- Microsoft Edge o Google Chrome actualizado. Un navegador es el programa que permite abrir páginas de Internet.
