# O que é necessário

<!-- Fonte: Manual App CRM 1.5.docx, secção 3.1. -->

- Um computador, telemóvel ou tablet autorizado pela empresa através do seu correio eletrónico empresarial.

- Ligação à Internet ou à rede empresarial correspondente.

- Uma conta empresarial com permissão para entrar no CRM.

- Microsoft Edge ou Google Chrome atualizado. Um navegador é o programa que permite abrir páginas da Internet.
