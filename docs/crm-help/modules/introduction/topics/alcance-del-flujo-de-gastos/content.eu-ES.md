# Gastu-fluxuaren irismena

<!-- Iturria: Manual App CRM 1.5.docx, 1.3 atala. -->

Lan-fluxu hau CRMaren web-aplikazioa aktibatuta duten erabiltzaileei aplikatzen zaie. Dagozkien kontabilitate- eta ordainketa-lanak Axaptan egiten jarraitzen dira, taldeko konpainia bakoitzaren profilaren eta barne-prozeduraren arabera.
