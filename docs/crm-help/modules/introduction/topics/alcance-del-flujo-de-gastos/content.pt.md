# Âmbito do fluxo de despesas

<!-- Fonte: Manual App CRM 1.5.docx, secção 1.3. -->

Este fluxo de trabalho aplica-se aos utilizadores que têm ativa a aplicação Web do CRM. As tarefas contabilísticas e de pagamento correspondentes continuam a ser realizadas no Axapta de acordo com o perfil e o procedimento interno de cada empresa do grupo.
