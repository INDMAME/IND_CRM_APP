# Alcance del flujo de gastos

<!-- Fuente: Manual App CRM 1.5.docx, sección 1.3. -->

Este flujo de trabajo se aplica a los usuarios que tienen activa la aplicación web del CRM. Las tareas contables y de pago que correspondan continúan realizándose en Axapta según el perfil y el procedimiento interno de cada compañía del grupo.
