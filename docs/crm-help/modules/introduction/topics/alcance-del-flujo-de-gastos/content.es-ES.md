# Alcance del flujo de gastos

<!-- Fuente: Manual App CRM 1.5.docx, sección 1.3. -->

Este flujo se aplica a las personas autorizadas para utilizar la aplicación web del CRM. En ella pueden preparar hojas de gastos, añadir líneas o tickets, consultar estados y realizar las acciones de aprobación que permita su perfil.

La visibilidad de empresas, personas y registros depende de los permisos de cada usuario. Un responsable puede disponer de opciones adicionales para consultar o decidir sobre las hojas de su equipo.

Las tareas contables y de pago continúan realizándose en Axapta según el perfil y el procedimiento interno de cada compañía. El CRM muestra después el estado correspondiente para que el usuario pueda seguir el resultado.
