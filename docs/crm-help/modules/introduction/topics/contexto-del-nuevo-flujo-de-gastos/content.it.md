# Contesto del nuovo flusso spese

<!-- Fonte: Manual App CRM 1.5.docx, sezione 1.1. -->

Nell'ambito dello sviluppo dell'applicazione web mobile CRM (https://crm.insertec.biz:7702), è stato definito e sviluppato un nuovo flusso di lavoro per la gestione delle note spese. Innanzitutto, rappresenta una digitalizzazione completa del processo, poiché scompaiono le note spese cartacee e le relative firme di «approvazione». Inoltre, è stata chiarita e aggiornata la gerarchia delle responsabilità per l'approvazione delle note spese.
