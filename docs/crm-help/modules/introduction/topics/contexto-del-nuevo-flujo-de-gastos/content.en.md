# Context of the new expense workflow

<!-- Source: CRM App Manual 1.5.docx, section 1.1. -->

As part of the development of the CRM mobile web application (https://crm.insertec.biz:7702), a new workflow for managing expense sheets has been defined and developed. First, it provides comprehensive digitalization of the process, as printed expense sheets and their approval signatures are no longer used. In addition, the responsibility hierarchy for approving expense sheets has been clarified and updated.
