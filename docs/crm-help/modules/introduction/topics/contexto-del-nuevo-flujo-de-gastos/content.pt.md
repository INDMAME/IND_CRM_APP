# Contexto do novo fluxo de despesas

<!-- Fonte: Manual App CRM 1.5.docx, secção 1.1. -->

No âmbito do desenvolvimento da aplicação Web móvel do CRM (https://crm.insertec.biz:7702), foi definido e desenvolvido um novo fluxo de trabalho para a gestão das folhas de despesas. Em primeiro lugar, este representa uma digitalização integral do processo, pois deixam de existir as folhas de despesas em papel e as respetivas assinaturas de «aprovação». Por outro lado, a hierarquia de responsabilidade pela aprovação das folhas de despesas foi clarificada e atualizada.
