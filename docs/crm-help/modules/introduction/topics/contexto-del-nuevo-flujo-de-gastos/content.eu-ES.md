# Gastu-fluxu berriaren testuingurua

<!-- Iturria: Manual App CRM 1.5.docx, 1.1 atala. -->

CRMaren web-aplikazio mugikorraren (https://crm.insertec.biz:7702) garapenaren barruan, gastu-orriak kudeatzeko lan-fluxu berri bat definitu eta garatu da. Lehenik eta behin, prozesua osorik digitalizatzea dakar, paperezko gastu-orriak eta haien «onespen» sinadurak desagertzen baitira. Bestalde, gastu-orriak onartzeko erantzukizun-hierarkia argitu eta eguneratu da.
