# 如何使用本手册

<!-- 来源：Manual App CRM 1.5.docx，第 2 节。 -->

本手册使用以下术语：

- 单击：将鼠标指针放在按钮上，并按一次鼠标左键。在手机或平板电脑上，是指用手指轻触一次。

- 输入：单击空白字段，然后使用键盘。

- 选择：打开列表并选择其中一个选项。

- 滚动：滚动鼠标滚轮，或用手指向上或向下滑动，以查看屏幕未显示的内容。

- 确认：在出现的窗口中接受操作。“取消”会关闭该窗口而不执行操作。

> **建议：** 请按所示顺序执行步骤。如果页面显示消息，请完整阅读后再单击。多次单击可能会重复某项操作，也可能使您难以判断刚才发生了什么。
