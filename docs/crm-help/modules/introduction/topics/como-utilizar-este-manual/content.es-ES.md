# Cómo utilizar este manual

<!-- Fuente: Manual App CRM 1.5.docx, sección 2. -->

En este documento se emplean las siguientes palabras:

- Pulsar o hacer clic: colocar el puntero sobre un botón y presionar una vez el botón izquierdo del ratón. En un teléfono o tableta significa tocar una vez con el dedo.

- Escribir: pulsar dentro de un campo vacío y utilizar el teclado.

- Seleccionar: abrir una lista y elegir una de sus opciones.

- Desplazarse: mover la rueda del ratón o deslizar el dedo hacia arriba o hacia abajo para ver contenido que no cabe en la pantalla.

- Confirmar: aceptar una acción en la ventana que aparece. Cancelar cierra esa ventana sin ejecutar la acción.

> **RECOMENDACIÓN:** Siga los pasos en el orden indicado. Si la pantalla muestra un mensaje, léalo por completo antes de volver a pulsar. Pulsar varias veces puede repetir una operación o dificultar saber qué ha ocurrido.
