# Eskuliburu hau nola erabili

<!-- Iturria: Manual App CRM 1.5.docx, 2. atala. -->

Dokumentu honetan hitz hauek erabiltzen dira:

- Sakatu edo klik egin: jarri erakuslea botoi baten gainean eta sakatu behin saguaren ezkerreko botoia. Telefono edo tableta batean, ukitu behin hatzarekin.

- Idatzi: sakatu eremu huts baten barruan eta erabili teklatua.

- Hautatu: ireki zerrenda bat eta aukeratu haren aukeretako bat.

- Mugitu: biratu saguaren gurpila edo irristatu hatza gora edo behera pantailan sartzen ez den edukia ikusteko.

- Berretsi: agertzen den leihoan ekintza bat onartu. Utzi aukerak leihoa ixten du ekintza gauzatu gabe.

> **GOMENDIOA:** Jarraitu urratsak adierazitako ordenan. Pantailak mezu bat erakusten badu, irakurri osorik berriro sakatu aurretik. Hainbat aldiz sakatzeak eragiketa bat errepika dezake edo gertatutakoa ulertzea zaildu.
