# Como utilizar este manual

<!-- Fonte: Manual App CRM 1.5.docx, secção 2. -->

Neste documento são utilizadas as seguintes palavras:

- Premir ou clicar: colocar o ponteiro sobre um botão e premir uma vez o botão esquerdo do rato. Num telemóvel ou tablet, significa tocar uma vez com o dedo.

- Escrever: premir dentro de um campo vazio e utilizar o teclado.

- Selecionar: abrir uma lista e escolher uma das opções.

- Deslocar: mover a roda do rato ou deslizar o dedo para cima ou para baixo para ver conteúdo que não cabe no ecrã.

- Confirmar: aceitar uma ação na janela apresentada. Cancelar fecha essa janela sem executar a ação.

> **RECOMENDAÇÃO:** Siga os passos pela ordem indicada. Se o ecrã apresentar uma mensagem, leia-a por completo antes de voltar a premir. Premir várias vezes pode repetir uma operação ou dificultar a identificação do que aconteceu.
