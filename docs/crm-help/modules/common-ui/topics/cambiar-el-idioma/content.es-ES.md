# Cambiar el idioma

<!-- Fuente: Manual App CRM 1.5.docx, sección 6.2. -->

## Objetivo

Seleccionar el idioma de los menús, botones y mensajes del CRM.

## Antes de empezar

Guarde o cancele cualquier edición pendiente antes de cambiar el idioma, ya que la pantalla volverá a cargarse. Las instrucciones de este manual utilizan los nombres de los controles en español.

## Pasos

1. Abra el menú lateral y pulse su nombre de usuario.
2. Pulse **Idiomas** para desplegar las opciones.
3. Seleccione **Español**, **Euskara**, **English**, **Português**, **Italiano** o **简体中文**, según el idioma que desea utilizar.
4. Espere a que la pantalla vuelva a cargarse antes de continuar.

## Resultado y comprobación

Abra de nuevo el menú de usuario y compruebe el idioma seleccionado. Revise un texto de la interfaz, como el nombre de una acción o de un menú. Los datos de negocio, como las descripciones escritas por los usuarios, no se traducen al cambiar esta opción.

## Variantes e incidencias

Si los textos de la interfaz no corresponden al idioma elegido después de la recarga, anote la pantalla y el idioma seleccionado para comunicárselo a soporte. Para volver al idioma anterior, repita los mismos pasos.
