# Profili del flusso spese

<!-- Fonte: Manual App CRM 1.5.docx, sezione 6.4. -->

I profili utente sono tre:

- Utente standard: può creare e gestire le proprie note spese.

- Utente approvatore: può creare note spese e verificare quelle delle persone di sua competenza.

- Utente pagatore: può creare note spese e continuare in Axapta le attività contabili e di pagamento di propria competenza.

La gerarchia delle responsabilità per l'approvazione è definita in Axapta. Dal CRM, ogni utente può consultare esclusivamente i propri record e, quando dispone delle autorizzazioni di gestione, quelli dei subordinati autorizzati.
