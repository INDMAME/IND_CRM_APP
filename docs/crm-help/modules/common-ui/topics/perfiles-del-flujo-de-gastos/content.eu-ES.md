# Gastuen lan-fluxuko profilak

<!-- Iturria: Manual App CRM 1.5.docx, 6.4 atala. -->

Hiru erabiltzaile-profil daude:

- Erabiltzaile estandarra: bere gastu-orriak sor eta kudea ditzake.

- Erabiltzaile onartzailea: gastu-orriak sor ditzake eta bere ardurapeko pertsonen orriak berrikusi.

- Erabiltzaile ordaintzailea: gastu-orriak sor ditzake eta Axaptan dagozkion kontabilitate- eta ordainketa-lanekin jarraitu.

Onarpenerako erantzukizun-hierarkia Axaptan definituta dago. CRMtik, erabiltzaile bakoitzak bere erregistroak baino ezin ditu kontsultatu, eta, kudeaketa-baimenak dituenean, baimenduta dituen mendeko pertsonenak ere bai.
