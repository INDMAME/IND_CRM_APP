# Expense workflow roles

<!-- Source: CRM App Manual 1.5.docx, section 6.4. -->

There are three user roles:

- Standard user: can create and manage their expense sheets.

- Approver user: can create expense sheets and review the sheets of the people they manage.

- Payer user: can create expense sheets and continue the relevant accounting and payment tasks in Axapta.

The responsibility hierarchy for approval is defined in Axapta. From the CRM, each user can view only their own records and, when they have management permissions, those of authorized subordinates.
