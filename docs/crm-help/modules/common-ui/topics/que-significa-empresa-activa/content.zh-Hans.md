# 当前公司的含义

<!-- 来源：Manual App CRM 1.5.docx，第 6.1 节。 -->

当前公司决定您可以查看哪些客户、项目、币种、拜访、费用单和票据。创建或搜索信息之前，请确认您正在正确的公司中操作。

![与“当前公司的含义”相关的截图：当前公司决定您可以查看哪些客户、项目、币种、拜访、费用单和票据。创建或搜索信息之前，请确认您正在正确的公司中操作。](../../../../assets/manual-1.5/image8.png)

1. 打开侧边菜单，然后单击底部的用户名。

2. 单击“公司”。

3. 选择您要操作且已获授权的公司。

4. 等待页面刷新后再继续。

> **重要提示：** 当前公司不正确时，请勿创建记录。之后更换公司并不会自动转移已创建的记录。
