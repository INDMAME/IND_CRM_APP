# Enpresa aktiboa zer den

<!-- Iturria: Manual App CRM 1.5.docx, 6.1 atala. -->

Enpresa aktiboak zein bezero, proiektu, dibisa, bisita, gastu-orri eta tiket kontsulta ditzakezun zehazten du. Informazioa sortu edo bilatu aurretik, egiaztatu enpresa egokian ari zarela lanean.

![«Enpresa aktiboa zer den» ataleko pantaila-argazkia, honekin lotua: Enpresa aktiboak zein bezero, proiektu, dibisa, bisita, gastu-orri eta tiket kontsulta ditzakezun zehazten du. Informazioa sortu edo bilatu aurretik, egiaztatu...](../../../../assets/manual-1.5/image8.png)

1. Ireki alboko menua eta sakatu zure erabiltzaile-izena beheko aldean.

2. Sakatu Konpainiak.

3. Hautatu lan egiteko baimenduta duzun enpresa.

4. Jarraitu aurretik, itxaron pantaila eguneratu arte.

> **GARRANTZITSUA:** Ez sortu erregistrorik enpresa aktiboa zuzena ez bada. Gero enpresaz aldatzeak ez du lehendik sortutako erregistro bat automatikoki lekualdatzen.
