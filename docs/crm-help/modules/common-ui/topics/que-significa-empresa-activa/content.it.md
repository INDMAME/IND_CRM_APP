# Cosa significa società attiva

<!-- Fonte: Manual App CRM 1.5.docx, sezione 6.1. -->

La società attiva determina i clienti, i progetti, le valute, le visite, le note spese e i ticket che è possibile consultare. Prima di creare o cercare informazioni, verificare di lavorare nella società corretta.

![Schermata di «Cosa significa società attiva» relativa a: La società attiva determina i clienti, i progetti, le valute, le visite, le note spese e i ticket che è possibile consultare. Prima di creare o cercare informazioni, verificare di lavorare nella società corretta.](../../../../assets/manual-1.5/image8.png)

1. Aprire il menu laterale e premere il proprio nome utente nella parte inferiore.

2. Premere Società.

3. Selezionare la società autorizzata con cui si intende lavorare.

4. Attendere che la schermata venga aggiornata prima di continuare.

> **IMPORTANTE:** Non creare un record se la società attiva non è quella corretta. Cambiare società in seguito non trasferisce automaticamente un record già creato.
