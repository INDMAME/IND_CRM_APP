# Edit, save, and cancel

<!-- Source: CRM App Manual 1.5.docx, section 5.1. -->

On a detail screen, data may be locked to prevent accidental changes. If you have permission, press Edit to enable the fields. After changing the data, press Save. The application will display a confirmation; confirm only after reviewing the information. Press Cancel if you want to discard unsaved changes.

UNSAVED CHANGES: If you try to go back, close, or move to another screen while an edit is pending, the CRM may warn you. Choose to stay if you need to save; choose to leave only if you accept losing the changes.
