# Editar, guardar e cancelar

<!-- Fonte: Manual App CRM 1.5.docx, secção 5.1. -->

Num ecrã de detalhe, os dados podem aparecer bloqueados para evitar alterações acidentais. Se tiver permissão, prima Editar para ativar os campos. Depois de alterar os dados, prima Guardar. A aplicação apresentará uma confirmação; confirme apenas depois de rever a informação. Prima Cancelar se pretender rejeitar as alterações não guardadas.

ALTERAÇÕES NÃO GUARDADAS: Se tentar voltar, fechar ou mudar de ecrã enquanto existir uma edição pendente, o CRM poderá avisá-lo. Escolha permanecer se precisar de guardar; escolha sair apenas se aceitar perder as alterações.
