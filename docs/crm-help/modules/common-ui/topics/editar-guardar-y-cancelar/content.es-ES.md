# Editar, guardar y cancelar

<!-- Fuente: Manual App CRM 1.5.docx, sección 5.1. -->

En una pantalla de detalle, los datos pueden aparecer bloqueados para evitar cambios accidentales. Si dispone de permiso, pulse Editar para habilitar los campos. Después de modificar los datos, pulse Guardar. La aplicación mostrará una confirmación; confirme solo después de revisar la información. Pulse Cancelar si desea descartar los cambios no guardados.

CAMBIOS SIN GUARDAR: Si intenta volver, cerrar o cambiar de pantalla mientras existe una edición pendiente, el CRM puede advertirle. Elija permanecer si necesita guardar; elija salir solo si acepta perder los cambios.
