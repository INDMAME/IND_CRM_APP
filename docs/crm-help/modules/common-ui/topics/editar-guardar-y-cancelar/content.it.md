# Modificare, salvare e annullare

<!-- Fonte: Manual App CRM 1.5.docx, sezione 5.1. -->

In una schermata di dettaglio, i dati possono apparire bloccati per evitare modifiche accidentali. Se si dispone dell'autorizzazione, premere Modifica per abilitare i campi. Dopo aver modificato i dati, premere Salva. L'applicazione mostrerà una conferma; confermare solo dopo aver verificato le informazioni. Premere Annulla se si desidera ignorare le modifiche non salvate.

MODIFICHE NON SALVATE: Se si tenta di tornare indietro, chiudere o cambiare schermata mentre è presente una modifica in sospeso, il CRM può visualizzare un avviso. Scegliere di rimanere se occorre salvare; scegliere di uscire solo se si accetta di perdere le modifiche.
