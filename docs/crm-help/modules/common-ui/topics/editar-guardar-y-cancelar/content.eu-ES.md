# Editatu, gorde eta utzi

<!-- Iturria: Manual App CRM 1.5.docx, 5.1 atala. -->

Xehetasun-pantaila batean, datuak blokeatuta ager daitezke ustekabeko aldaketak saihesteko. Baimena baduzu, sakatu Editatu eremuak gaitzeko. Datuak aldatu ondoren, sakatu Gorde. Aplikazioak berrespen bat erakutsiko du; berretsi informazioa berrikusi ondoren bakarrik. Sakatu Utzi gorde gabeko aldaketak baztertu nahi badituzu.

GORDE GABEKO ALDAKETAK: Editatze-lan bat amaitu gabe dagoela atzera egiten, ixten edo pantailaz aldatzen saiatzen bazara, CRMak ohartarazi diezazuke. Hautatu bertan geratzea gorde behar baduzu; hautatu irtetea aldaketak galtzea onartzen baduzu bakarrik.
