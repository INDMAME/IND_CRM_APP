# Autorizzazioni

<!-- Fonte: Manual App CRM 1.5.docx, sezione 6.3. -->

Le autorizzazioni controllano quali menu, dati e pulsanti è possibile utilizzare. Un responsabile può vedere le note spese delle persone di sua competenza e disporre delle azioni di approvazione. Un utente privo di tali autorizzazioni vedrà esclusivamente le opzioni che gli spettano.

SE MANCA UN'OPZIONE: Non tentare di accedere tramite indirizzi copiati da un'altra persona. Verificare prima la società attiva e, se l'opzione continua a non comparire, richiedere la verifica delle proprie autorizzazioni tramite il consueto canale interno del gruppo in Microsoft Teams assegnato alla propria società.
