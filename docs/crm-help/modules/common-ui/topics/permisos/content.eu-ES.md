# Baimenak

<!-- Iturria: Manual App CRM 1.5.docx, 6.3 atala. -->

Baimenek zein menu, datu eta botoi erabil daitezkeen kontrolatzen dute. Arduradun batek bere ardurapeko pertsonen gastu-orriak ikus ditzake eta onarpen-ekintzak izan ditzake. Baimen horiek ez dituen erabiltzaileak berari dagozkion aukerak baino ez ditu ikusiko.

AUKERA BAT FALTA BADA: Ez saiatu beste pertsona bati kopiatutako helbideen bidez sartzen. Egiaztatu lehenik enpresa aktiboa, eta aukerak agertzen jarraitzen ez badu, eskatu zure baimenak berrikusteko zure konpainiari Microsoft Teams-en esleitutako taldearen ohiko barne-kanalaren bidez.
