# Permissions

<!-- Source: CRM App Manual 1.5.docx, section 6.3. -->

Permissions control which menus, data, and buttons you can use. A manager may see expense sheets belonging to the people they manage and have access to approval actions. A user without those permissions will see only the relevant options.

IF AN OPTION IS MISSING: Do not try to access it using addresses copied from another person. First check the active company and, if the option still does not appear, request a review of your permissions through the group's usual internal Microsoft Teams channel assigned to your company.
