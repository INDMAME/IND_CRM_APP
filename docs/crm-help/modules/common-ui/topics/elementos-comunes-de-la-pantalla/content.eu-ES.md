# Pantailaren elementu komunak

<!-- Iturria: Manual App CRM 1.5.docx, 5. atala. -->

Modulu bakoitzak eremu desberdinak izan arren, aplikazioak hainbat elementu errepikatzen ditu. Behin ikasteak eskuliburuaren gainerakoa errazten du.

- Alboko menua: menu-botoiarekin irekitzen da, eta Bisitak, Gastuak, Gastu-orriak eta Tiketak ataletan sartzeko aukera ematen du, erabiltzaileak baimena badu.

- Goiko barra: pantailaren izena erakusten du, eta Atzera, Sortu, Editatu, Gorde, Utzi, Ezabatu, Iragazkia edo Eguneratu aukerak izan ditzake.

- Eduki-eremua: inprimakiak, iragazkiak, txartelak eta emaitzak agertzen diren erdialdea.

- Botoi mugikorra: normalean beheko eskuineko izkina batean dagoen botoi biribila. Erregistro bat sor dezake edo ekintza azkarrak zabaldu.

- Berrespen-mezuak: ekintza garrantzitsu baten aurretik azken onespena eskatzen duten leihoak.

- Errore- edo baimen-mezuak: ekintza bat zergatik ezin izan den egin azaltzen dute. Berriro saiatu aurretik irakurri behar dira.
