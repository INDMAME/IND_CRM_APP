# Elementos comuns do ecrã

<!-- Fonte: Manual App CRM 1.5.docx, secção 5. -->

Embora cada módulo tenha campos diferentes, a aplicação repete vários elementos. Aprendê-los uma vez facilita a consulta do resto do manual.

- Menu lateral: abre-se com o botão de menu e permite entrar em Visitas, Despesas, Folhas de despesas e Tickets, desde que o utilizador tenha permissão.

- Barra superior: mostra o nome do ecrã e pode incluir Voltar, Criar, Editar, Guardar, Cancelar, Eliminar, Filtro ou Atualizar.

- Área de conteúdo: parte central onde aparecem formulários, filtros, cartões e resultados.

- Botão flutuante: botão redondo normalmente situado num canto inferior direito. Pode criar um registo ou apresentar ações rápidas.

- Mensagens de confirmação: janelas que solicitam uma última aceitação antes de uma ação importante.

- Mensagens de erro ou de permissão: explicam por que motivo não foi possível realizar uma ação. Devem ser lidas antes de voltar a tentar.
