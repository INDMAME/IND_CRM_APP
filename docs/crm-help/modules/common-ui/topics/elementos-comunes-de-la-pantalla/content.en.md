# Common screen elements

<!-- Source: CRM App Manual 1.5.docx, section 5. -->

Although each module has different fields, the application reuses several elements. Learning them once makes the rest of the manual easier to follow.

- Side menu: opens with the menu button and provides access to Visits, Expenses, Expense Sheets, and Tickets, provided that the user has permission.

- Top bar: displays the screen name and may include Back, Create, Edit, Save, Cancel, Delete, Filter, or Refresh.

- Content area: the central area where forms, filters, cards, and results appear.

- Floating button: a round button normally located in a lower-right corner. It may create a record or display quick actions.

- Confirmation messages: windows that request final confirmation before an important action.

- Error or permission messages: explain why an action could not be completed. Read them before trying again.
