# Elementos comunes de la pantalla

<!-- Fuente: Manual App CRM 1.5.docx, sección 5. -->

Aunque cada módulo tiene campos diferentes, la aplicación repite varios elementos. Aprenderlos una vez facilita el resto del manual.

- Menú lateral: se abre con el botón de menú y permite entrar en Visitas, Gastos, Hojas de gastos y Tickets, siempre que el usuario tenga permiso.

- Barra superior: muestra el nombre de la pantalla y puede incluir Volver, Crear, Editar, Guardar, Cancelar, Eliminar, Filtro o Actualizar.

- Área de contenido: parte central donde aparecen formularios, filtros, tarjetas y resultados.

- Botón flotante: botón redondo situado normalmente en una esquina inferior derecha. Puede crear un registro o desplegar acciones rápidas.

- Mensajes de confirmación: ventanas que solicitan una última aceptación antes de una acción importante.

- Mensajes de error o permiso: explican por qué una acción no se ha podido realizar. Deben leerse antes de reintentar.
