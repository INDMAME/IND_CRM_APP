# Actions available in Axapta

<!-- Source: CRM App Manual 1.5.docx, section 11.2.4. -->

For each expense sheet, the available actions depend on its status and the permissions of the user in the Axapta session:

- Request approval: the user who created the expense sheet requests approval from their manager.

- Undo request: the user cancels the approval request and returns the sheet to Draft so it can be modified.

- Approve: a manager approves the expense sheet and authorizes the process to continue.

- Undo approval: a manager reverses the approval of the expense sheet.

- Reject: a manager rejects the expense sheet.

- Undo rejection: a manager reverses the rejection of the expense sheet.
