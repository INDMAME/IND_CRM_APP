# Gestión de hojas de gastos

<!-- Fuente: Manual App CRM 1.5.docx, sección 11.2.2. -->

Esta pantalla permite consultar varias hojas y ejecutar las acciones disponibles sin abrir primero el formulario tradicional.

1. Abra `CRM / Asuntos / Hojas de Gastos / Gestión de Hojas de Gastos`.

2. Revise el usuario de la cabecera. Un responsable puede seleccionar a las personas subordinadas que tiene autorizadas; un usuario estándar solo puede seleccionar su propio usuario.

3. Utilice el filtro Estado para mostrar todas las hojas o limitar la lista a Borrador, Aprobación solicitada, Aprobado, Rechazado o Pagado.

4. Localice la hoja en las líneas y compruebe su identificador, propietario y estado.

5. Seleccione la hoja y ejecute únicamente una de las acciones que estén habilitadas. Las opciones dependen del estado y de sus permisos.

Si una persona o una acción no aparece, actualice el formulario y confirme que el usuario y la compañía de Axapta son correctos. Si continúa sin aparecer, consulte sus permisos con el área responsable.
