# Gestión de hojas de gastos

<!-- Fuente: Manual App CRM 1.5.docx, sección 11.2.2. -->

Esta nueva opción está disponible en el menú: CRM / Asuntos / Hojas de Gastos / Gestión de Hojas de Gastos.

![Captura de «Gestión de hojas de gastos» relacionada con: Esta nueva opción está disponible en el menú: CRM / Asuntos / Hojas de Gastos / Gestión de Hojas de Gastos.](../../../../assets/manual-1.5/image52.png)

![Captura de «Gestión de hojas de gastos» relacionada con: Esta nueva opción está disponible en el menú: CRM / Asuntos / Hojas de Gastos / Gestión de Hojas de Gastos.](../../../../assets/manual-1.5/image53.png)

Un responsable de equipo puede ver las personas subordinadas autorizadas en la cabecera de este formulario. Un usuario estándar solamente puede ver su propio usuario. En las líneas del formulario se muestran todas las hojas de gastos del usuario seleccionado en la cabecera.
