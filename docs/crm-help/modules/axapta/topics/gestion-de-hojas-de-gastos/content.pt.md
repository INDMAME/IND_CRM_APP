# Gestão de folhas de despesas

<!-- Fonte: Manual App CRM 1.5.docx, secção 11.2.2. -->

Esta nova opção está disponível no menu: CRM / Assuntos / Folhas de Despesas / Gestão de Folhas de Despesas.

![Captura de «Gestão de folhas de despesas» relacionada com: Esta nova opção está disponível no menu: CRM / Assuntos / Folhas de Despesas / Gestão de Folhas de Despesas.](../../../../assets/manual-1.5/image52.png)

![Captura de «Gestão de folhas de despesas» relacionada com: Esta nova opção está disponível no menu: CRM / Assuntos / Folhas de Despesas / Gestão de Folhas de Despesas.](../../../../assets/manual-1.5/image53.png)

Um responsável de equipa pode ver as pessoas subordinadas autorizadas no cabeçalho deste formulário. Um utilizador padrão só pode ver o seu próprio utilizador. Nas linhas do formulário, são apresentadas todas as folhas de despesas do utilizador selecionado no cabeçalho.
