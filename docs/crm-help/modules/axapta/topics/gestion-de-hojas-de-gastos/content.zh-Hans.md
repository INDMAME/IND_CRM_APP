# 费用单管理

<!-- 来源：Manual App CRM 1.5.docx，第 11.2.2 节。 -->

此新选项位于以下菜单中：CRM / 事务 / 费用单 / 费用单管理。

![与“费用单管理”相关的截图：此新选项位于以下菜单中：CRM / 事务 / 费用单 / 费用单管理。](../../../../assets/manual-1.5/image52.png)

![与“费用单管理”相关的截图：此新选项位于以下菜单中：CRM / 事务 / 费用单 / 费用单管理。](../../../../assets/manual-1.5/image53.png)

团队负责人可以在此表单的表头中看到已获授权的下属人员。标准用户只能看到自己。表单的明细行中会显示表头所选用户的全部费用单。
