# Gestione delle note spese

<!-- Fonte: Manual App CRM 1.5.docx, sezione 11.2.2. -->

Questa nuova opzione è disponibile nel menu: CRM / Questioni / Note spese / Gestione note spese.

![Schermata di «Gestione delle note spese» relativa a: Questa nuova opzione è disponibile nel menu: CRM / Questioni / Note spese / Gestione note spese.](../../../../assets/manual-1.5/image52.png)

![Schermata di «Gestione delle note spese» relativa a: Questa nuova opzione è disponibile nel menu: CRM / Questioni / Note spese / Gestione note spese.](../../../../assets/manual-1.5/image53.png)

Un responsabile di team può vedere i subordinati autorizzati nell'intestazione di questo modulo. Un utente standard può vedere solo il proprio utente. Nelle righe del modulo vengono visualizzate tutte le note spese dell'utente selezionato nell'intestazione.

Nella parte superiore è presente un filtro per lo stato della nota spese. È un elenco a discesa che contiene tutte le opzioni possibili:
