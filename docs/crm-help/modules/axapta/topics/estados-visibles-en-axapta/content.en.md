# Statuses visible in Axapta

<!-- Source: CRM App Manual 1.5.docx, section 11.2.3. -->

- Draft: the user is preparing the expense sheet but has not yet finished it.

- Approval requested: the user has finished the expense sheet and requested approval from their manager.

- Approved: the manager has approved the expense sheet.

- Rejected: the manager has rejected the expense sheet.

- Paid: the administration team has posted the payment in Axapta.
