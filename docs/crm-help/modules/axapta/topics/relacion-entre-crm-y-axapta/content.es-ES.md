# Relación entre CRM y Axapta

<!-- Fuente: Manual App CRM 1.5.docx, sección 11.1. -->

Las hojas y sus líneas creadas en la aplicación web se integran con Axapta y pueden consultarse allí mediante el mismo identificador de hoja. Los perfiles administrativos continúan en Axapta las tareas contables y de pago que les correspondan.

Para el usuario habitual, el trabajo diario descrito en este manual se realiza en la aplicación web. No es necesario abrir Axapta para crear líneas, adjuntar tickets o solicitar aprobación, salvo que su puesto y el procedimiento interno indiquen lo contrario.

Cuando el proceso contable o el pago avanza en Axapta, la hoja mostrará el estado Pagado quedando solo en modo lectura en el CRM. Si los datos no parecen actualizados, no duplique la hoja: actualice la pantalla y contacte con el área responsable si la diferencia continúa.
