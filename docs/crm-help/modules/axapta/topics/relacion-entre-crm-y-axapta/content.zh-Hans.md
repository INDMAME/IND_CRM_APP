# CRM 与 Axapta 的关系

<!-- 来源：Manual App CRM 1.5.docx，第 11.1 节。 -->

在 Web 应用中创建的费用单及其费用行会与 Axapta 集成，并可在那里使用同一费用单标识符进行查看。行政角色会继续在 Axapta 中执行其负责的会计和付款任务。

对于普通用户，本手册所述的日常工作均在 Web 应用中完成。无需打开 Axapta 即可创建费用行、附加票据或申请审批，除非您的岗位和内部流程另有要求。

当会计流程或付款在 Axapta 中推进后，费用单会显示“已付款”状态，并在 CRM 中变为只读。如果数据似乎未更新，请勿重复创建费用单；请刷新页面，如果差异仍然存在，请联系负责部门。
