Permisos y visibilidad en Visitas

Explicación funcional. Actualizado: 2026-06-09.

Resumen

En Visitas se combinan dos controles: el permiso del módulo y la jerarquía de usuarios. El permiso del módulo define si una persona puede entrar, consultar, crear o modificar. La jerarquía define qué visitas puede ver.

Idea clave: una persona solo trabaja con las visitas que le corresponden por su permiso y por su posición dentro de la jerarquía.

1. Permiso para entrar al módulo

Lo primero que se comprueba es si la persona tiene acceso al módulo de Visitas. Según su nivel de permiso, la web le permite unas acciones u otras.

  • Si no tiene acceso, no debería poder entrar al módulo.
  • Si solo tiene permiso de consulta, puede ver las visitas que le correspondan, pero no crear ni modificar.
  • Si tiene permiso para crear, la web le muestra la opción de crear nuevas visitas.
  • Si tiene permiso para modificar, puede editar dentro de los límites marcados por la jerarquía y las reglas del sistema.

2. Qué visitas puede ver cada persona

Después de comprobar el permiso del módulo, se aplica la jerarquía. Esta jerarquía indica qué usuarios están dentro del alcance de cada persona.

Persona sin equipo a cargo

  • Normalmente ve sus propias visitas.
  • Si tiene permiso de crear, puede registrar nuevas visitas propias.
  • Si solo tiene permiso de consulta, únicamente puede revisarlas.

Responsable con equipo

  • Puede ver sus visitas y las visitas de las personas que dependen de él, según la jerarquía configurada.
  • Puede filtrar el historial por una persona concreta de su equipo.
  • Si deja el filtro en todos, verá todas las visitas que tiene permitido consultar.

Persona con alcance ampliado

  • Puede ver un conjunto más amplio de usuarios si así lo define la jerarquía.
  • La web no le muestra usuarios que estén fuera de su alcance.
  • El filtro siempre se limita a las personas que realmente puede consultar.

3. Cómo funciona el filtro de personas

Cuando una persona puede ver visitas de varios usuarios, la web muestra un selector para elegir de quién quiere ver las visitas.

Filtro en todos

  • La persona ve todas las visitas permitidas por su jerarquía.
  • No significa ver todas las visitas de la empresa, solo las que entran en su alcance.

Filtro por una persona concreta

  • La persona ve únicamente las visitas del usuario seleccionado.
  • Solo se pueden seleccionar usuarios que ya están dentro de su jerarquía visible.

4. Crear o modificar visitas

Poder ver una visita no significa automáticamente poder cambiarla. Para crear o modificar se necesita permiso de acción, además de estar dentro del alcance permitido.

Crear

La opción de crear aparece cuando la persona tiene permiso para registrar nuevas visitas. Si no lo tiene, puede consultar lo permitido, pero no crear.

Modificar

Para modificar una visita, la persona debe tener permiso para editar y la visita debe estar dentro de su alcance. La jerarquía no amplía permisos de edición por sí sola.

Consultar

Si la persona solo tiene permiso de consulta, podrá revisar las visitas visibles, pero no cambiar su contenido.

Regla sencilla

Permiso del módulo + jerarquía = lo que puede hacer una persona en Visitas.

El permiso del módulo decide si puede entrar, consultar, crear o modificar. La jerarquía decide sobre qué visitas puede aplicar esas acciones. La web une ambas cosas para que cada persona vea y gestione solo lo que le corresponde.
